⏱️ Chronix — Digital Clock

Um relógio digital moderno, minimalista e responsivo, desenvolvido para oferecer uma experiência visual elegante e simples.

✨ Funcionalidades

- 🕒 Exibição de horário em tempo real.
- 🔄 Alternância entre formatos 12h e 24h.
- 📅 Exibição de data.
- 🎨 Interface moderna com tema Dark.
- 📱 Layout responsivo.
- ⚡ Atualização automática do horário.

🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

🎨 Design

O Chronix possui uma interface inspirada no estilo Dark Modern, com tons escuros, detalhes em Neon Teal e tipografia minimalista.

🚀 Como executar

1. Clone este repositório:
   git clone URL_DO_REPOSITORIO
2. Abra a pasta do projeto.
3. Execute o arquivo "index.html" no navegador.

📂 Estrutura do projeto

├── index.html
├── style.css
